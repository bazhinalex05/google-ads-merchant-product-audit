# Changelog

## Unreleased

- Очищення попереднього експорту перенесено після успішного отримання всіх сторінок Merchant API: помилка читання не залишає Products порожнім.

- Виправлено адресацію запису Products: пакети записуються послідовно від A2 за індексом масиву, без повторного визначення останнього рядка; перед журналом завершення застосовуються відкладені зміни таблиці.

- Перероблено тестову версію під вузький експорт: скрипт ставить `Products` першим листом і пише туди тільки `ID` та `Product Type`.
- Додано дедуплікацію за `ID`: якщо Merchant API повертає дубль, скрипт залишає одну строку і бере непорожній або повніший `Product Type`.
- Старі згенеровані листи `ProductTypeExport`, `ProductTypes` і `Brands` видаляються при запуску.

## v1.0.0 - 2026-08-23

- Перша версія перенесена з Google Docs у GitHub.
